# Sports practice planner

This is a static Telugu/English sports practice planner. Its question form creates Google search links for general web results, official sports organizations, and health authorities. It does not generate summaries inside the site and needs no API key.

## Publish with Netlify Drop

1. Open https://app.netlify.com/drop.
2. Drag the `publish-ready` folder from this project onto the page.
3. Netlify will give you a `netlify.app` preview URL. Sign in and claim the site to keep it in your account.

The `publish-ready` folder contains only the static site files for this deployment.
